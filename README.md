# Cram

**Study smarter.** A bring‑your‑own‑key AI study‑set maker.

- 📚 **Any source** — paste notes, an article or a transcript, or snap a textbook page.
- ✨ **One tap →** a recitable summary, key points to memorise, 8–16 flashcards and an 8‑question multiple‑choice quiz with explanations.
- 🃏 **Cards** — flip, mark "know it / still learning", mastery bar per set and overall.
- 🧪 **Quiz** — instant feedback, best score kept.
- 💬 **Ask** — a tutor grounded in the set: "explain like I'm 12", "give me a mnemonic".
